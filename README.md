# Ритм города

Учебный сайт музыкального фестиваля и CMS магазина билетов на PHP и MySQL. Покупатель может создать аккаунт, войти, сменить пароль, купить билет и увидеть заказ в личном кабинете. Администратор управляет билетами, заказами, анкетами и текстом главной страницы.

## Быстрый запуск на текущем ПК (Linux)

База `ritm_goroda` и локальный `app/config.php` уже настроены. Если MySQL остановлен, запустите его командой `mysql-start`. Затем:

```bash
cd /home/dennrbone/arina
./bin/start_local.sh
```

Откройте [главную страницу](http://127.0.0.1:8000/), [регистрацию покупателя](http://127.0.0.1:8000/account.php?view=register) или [вход администратора](http://127.0.0.1:8000/admin/index.php). Администратора создают командой `php bin/create_admin.php`. Остановить веб-сервер можно сочетанием `Ctrl+C` в его терминале.

## Установка на другом компьютере

Нужны PHP 8.2+, MySQL 8 и расширение `pdo_mysql`. Для новой базы выполните `database/schema.sql`. Для базы предыдущей версии проекта однократно выполните `database/upgrade_accounts.sql` после резервного копирования. Скопируйте `app/config.example.php` в `app/config.php` и задайте подключение к MySQL.

На Windows проект подготовлен для Open Server Panel 6: `.osp/project.ini` направляет веб-сервер в `public/`. Подробные команды и перенос базы приведены в [инструкции для Windows](Инструкция_запуск_и_перенос_Windows.docx).
