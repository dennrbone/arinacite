# Отчёт о доработке сайта «Ритм города»

К сайту регистрации на музыкальный фестиваль добавлен файл script.js. Форма по-прежнему содержит разделы личной информации, билета, музыкальных предпочтений и дополнительных услуг.

## Функции JavaScript: 4

1. updateSatisfaction — показывает рядом с ползунком текущую оценку от 0 до 10.
2. revealOnScroll — плавно показывает разделы страницы, когда они попадают в область просмотра.
3. handleSubmit — после проверки обязательных полей показывает сообщение о заполненной анкете и не перезагружает страницу.
4. handleReset — скрывает сообщение и возвращает отображаемую оценку к исходному значению после очистки формы.

## Анимации: 2

1. Разделы страницы плавно появляются снизу при прокрутке (изменение прозрачности и положения).
2. Сообщение после заполнения формы плавно появляется под кнопками.

Если в системе включено уменьшение движения, анимации отключаются.

## Как открыть сайт

Откройте файл /home/dennrbone/arina/index.html в браузере. Файлы style.css и script.js должны лежать рядом с ним. Сервер для просмотра не нужен.

Сайт демонстрационный: данные анкеты не сохраняются и никому не отправляются.

## Проверка

В Chromium проверены обязательные поля, обновление оценки, сообщение после заполнения, очистка формы и появление раздела при прокрутке.
